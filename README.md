# Запуск

установка - `npm i`
клиент - `npm run dev`
мок сервер - `npm run api`
линтер - `npm run lint`

# Технологии

-Выбрана упращенная архитектура FSD

-Реализованна упрощенная авторизация, с использованием мок функции. Т.к. полноценная требует написания серверной логики.

-Упростил нумерацию заказов до id
